J&K Studio Uploader

민간조사 탐정 J&K 채널 전용 내부 도구 · Internal tool for the J&K channel

소개

J&K Studio Uploader 는 민간조사 탐정 J&K 가 직접 제작한 영상을 자사 YouTube 채널에만 올리기 위해 쓰는 내부 도구입니다. 외부 사용자에게 제공되는 서비스가 아니며, 채널 운영자 한 명만 사용합니다.

  • YouTube API 서비스로 하는 일: 자사 채널에 영상 업로드, 썸네일 등록
  • 다른 사람의 계정·채널·영상·시청자 정보에는 접근하지 않습니다

About

J&K Studio Uploader is an internal tool used by J&K Private Investigation to upload videos it produces to its own YouTube channel only. It is not offered to the public and has a single user, the channel operator.

  • Uses YouTube API Services to upload videos and set thumbnails on the operator's own channel
  • Does not access any other user's account, channel, videos or viewer data
