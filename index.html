J&K 채널 전용
영상 업로드 도구

마케팅 대행사 스튜디오피엘(studioPL)이 고객사 민간조사 탐정 J&K 의 위임을 받아, J&K 를 위해 제작한 영상을 J&K 의 YouTube 채널에만 올리는 내부 도구입니다.

An internal tool operated by studioPL, a marketing agency, to upload videos produced for its client J&K Private Investigation to J&K's own YouTube channel only.

내부 전용 · Internal only 사용자 1명 · Single user 채널 1개 · One channel 판매·배포 안 함 · Not distributed

사용 방식 · How it works

  1. 영상 완성 — 스튜디오피엘 제작팀이 J&K 채널용 쇼츠 영상과 썸네일을 완성합니다.
    Our team finishes a Short and its thumbnail for the J&K channel.
  2. 담당자 검토 — 채널 운영 담당자가 영상·제목·설명을 확인하고 업로드(또는 예약)를 결정합니다.
    The channel manager reviews the video, title and description and approves the upload or schedules it.
  3. 채널 연결 — 담당자가 J&K 채널의 Google 계정으로 한 번 승인합니다 (Google OAuth 2.0, 업로드 권한만).
    The manager authorizes once with the channel's Google account (Google OAuth 2.0, upload permission only).
  4. 업로드 — 도구가 YouTube API 서비스로 영상을 올리고 썸네일을 등록합니다. 모든 업로드는 '변경되거나 합성된 콘텐츠' 공개를 켭니다.
    The tool uploads the video and sets its thumbnail through YouTube API Services, always enabling the altered or synthetic content disclosure.

YouTube API 서비스 사용 · Use of YouTube API Services

이 도구는 YouTube API 서비스를 사용합니다. 사용하는 기능은 두 가지뿐입니다.
This tool uses YouTube API Services, for two functions only.

하는 일 · What it does

  • J&K 채널에 영상 업로드 (videos.insert)
  • 업로드한 영상의 썸네일 등록 (thumbnails.set)

하지 않는 일 · What it does not do

  • 다른 계정·채널·영상에 접근하지 않음
  • 시청자·구독자·댓글·분석 정보를 읽거나 저장하지 않음
  • YouTube 데이터를 외부에 제공하지 않음

도구 사용에는 YouTube 서비스 약관이 적용되고, Google 이 처리하는 정보에는 Google 개인정보처리방침이 적용됩니다. 권한은 언제든 Google 계정 → 서드파티 액세스에서 철회할 수 있습니다.
Use of the tool is subject to the YouTube Terms of Service; information processed by Google is governed by the Google Privacy Policy. Access can be revoked at any time from Google Account third-party access.
