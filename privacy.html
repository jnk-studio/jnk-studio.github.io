1. 대상

이 방침은 민간조사 탐정 J&K(이하 "운영자")가 자사 YouTube 채널에 영상을 올리기 위해 사용하는 내부 도구 J&K Studio Uploader(이하 "도구")에 적용됩니다. 도구는 외부에 제공되지 않으며 운영자 한 명만 사용합니다.

2. YouTube API 서비스 사용

도구는 YouTube API 서비스를 사용합니다. 도구를 사용하는 것은 YouTube 서비스 약관에 동의하는 것이며, Google 이 처리하는 정보에는 Google 개인정보처리방침이 적용됩니다.

3. 접근·사용하는 정보

  • 운영자 본인의 Google 계정으로 승인한 인증 토큰 (권한: YouTube 영상 업로드)
  • 이 토큰으로 하는 일: 자사 채널에 운영자가 제작한 영상을 올리고 썸네일을 등록하는 것뿐
  • 다른 사람의 계정·채널·영상, 시청자·구독자·댓글·분석 정보는 읽거나 수집하지 않습니다

4. 저장·공유

  • 인증 토큰은 운영자의 PC 에 접근이 제한된 설정 파일로만 저장되며, 외부 서버로 보내지 않습니다
  • 어떤 정보도 제3자에게 판매·제공·공유하지 않습니다
  • 이 웹페이지는 쿠키나 방문자 추적 도구를 사용하지 않습니다

5. 보관·삭제·권한 철회

  • 토큰은 도구를 사용하는 동안만 보관하며, 사용을 멈추면 운영자의 PC 에서 삭제합니다
  • 권한은 언제든 Google 계정 → 보안 → 서드파티 액세스에서 철회할 수 있고, 철회하면 도구는 더 이상 채널에 접근할 수 없습니다

1. Scope

This policy applies to J&K Studio Uploader (the "Tool"), an internal tool that J&K Private Investigation (the "Operator") uses to upload videos to its own YouTube channel. The Tool is not offered to the public and has a single user, the Operator.

2. Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool you agree to the YouTube Terms of Service. Information processed by Google is governed by the Google Privacy Policy.

3. Information accessed and how it is used

  • An OAuth token authorized by the Operator's own Google account (scope: YouTube video upload)
  • The token is used only to upload videos produced by the Operator to its own channel and to set their thumbnails
  • The Tool does not read or collect any other user's account, channel or videos, nor any viewer, subscriber, comment or analytics data

4. Storage and sharing

  • The token is stored only in an access-restricted configuration file on the Operator's own computer and is never sent to any other server
  • No information is sold, disclosed or shared with any third party
  • This web page uses no cookies or visitor tracking

5. Retention, deletion and revocation

  • The token is kept only while the Tool is in use and is deleted from the Operator's computer when use stops
  • Access can be revoked at any time at Google Account → Security → Third-party access; after revocation the Tool can no longer access the channel
